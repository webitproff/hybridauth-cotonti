# Telegram

файл (lib/Hybridauth/Provider/Telegram.php) используется в плагине для входа через Telegram. 
Он полностью актуален на июль 2026 и не требует никаких правок, потому что:

Реализует современный протокол OpenID Connect с PKCE (Authorization Code + Proof Key for Code Exchange), который Telegram официально поддерживает для OAuth-авторизации с марта 2024 года (см. https://core.telegram.org/bots/telegram-login).

Содержит все необходимые методы: authenticate() (начинает и завершает OAuth-поток), getUserProfile() (получает данные пользователя из JWT-токена), isConnected(), getAccessToken(), setAccessToken() и т.д.

Работает «из коробки» с нашей конфигурацией в hybridauth.config.php (секция Telegram с ключами id и secret).

Никакие дополнительные исправления не вносились — библиотека Hybridauth 3.x используется в плагине в оригинальном виде.


## Инструкция для получения ключей авторизации Telegram (Client ID и Client Secret). 

**Она основана на реальном опыте настройки и учитывает особенности текущего интерфейса BotFather.**

---

### Как получить Client ID и Client Secret для Telegram

1. **Создайте бота в Telegram**
   - Найдите в Telegram официального бота **@BotFather**.
   - Отправьте команду `/newbot`.
   - Укажите имя бота (например, `MySite Login Bot`).
   - Укажите юзернейм бота (обязательно должен заканчиваться на `bot`, например `MySiteLoginBot`).
   - После создания вы получите **токен** (вида `123456:ABC-DEF...`). Он нам не понадобится для авторизации, но сохраните его.


-----------

2. **Привяжите домен к боту**
   - В чате с BotFather отправьте `/setdomain`.
   - Выберите созданного бота, например **@MySiteLoginBot**.
   - В ответ на сообщение «Link your website…» отправьте ваш домен **без https://**, например `myproject.com`. 
   - Вы получите подтверждение «Success! Domain updated.».

3. **Получите ключи через мини-приложение BotFather**
   - В чате с BotFather нажмите кнопку **«Open»** или вообще открыть https://t.me/botfather?startapp - нам нужно именно окно приложения "BotFather" (смотреть скрин)
   - Выбираем из списка наших ботов, - нужного! если его нет - есть строка поиска, находим. Справа от имени бота "шеврон" вправо.
   - В мини-приложении скролим вниз и читаем каждый элемент списка меню, находим **Web Login** и кликакем снова по правому шеврону.
   - здесь будет какое-то сообщение, о прекращении и отключении режима Legacy, я не помню точно, - жмем ок.
   - Затем в поле "Redirect URIs" добавьте свой callback URL, например:  
     `https://myproject.com/hybridauth`  
     (этот адрес должен совпадать с параметром `callback` в вашем конфиге плагина).
   - После сохранения вам будут показаны **Client ID** (числовой) и **Client Secret** (длинная строка). Скопируйте их.

4. **Вставьте ключи в конфигурацию плагина**
   - Откройте файл `plugins/hybridauth/conf/hybridauth.config.php`.
   - Добавьте или отредактируйте секцию `Telegram`:
     ```
     'Telegram' => [
         'enabled' => true,
         'keys' => [
             'id'     => 'ЧИСЛОВОЙ_CLIENT_ID',
             'secret' => 'СТРОКА_CLIENT_SECRET'
         ],
         'scope' => 'openid profile',   // при необходимости добавьте 'phone'
     ],
     ```
   - Сохраните файл.

5. **Проверить в админке плагина поля**
   - Расширения => HybridAuth Авторизация => Администрирование
   там должно быть в таблице:
`Telegram` `telegram` `Да` `user_telegram_id` `user_telegram_url` `Созданы ✅` 
Если их нет - тыкаем в кнопочку "Создать недостающие поля"
